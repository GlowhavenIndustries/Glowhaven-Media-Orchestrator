How it works

Export playlist metadata in three simple steps.

1

Select a media source

Spotify is available now, with additional connectors supported via the plugin registry.

2

Metadata extraction

Track names, artists, albums, durations, and timestamps are retrieved on demand.

3

Download CSV

A clean, formula-injection neutralized CSV is generated in memory for direct download.

Core capabilities

Structured Metadata

Track numbers, durations, and timestamps provide complete metadata context.

API Pagination Handling

Automatically traverses paginated API results for large playlists.

Stateless & Local-First

No playlist database required; credentials remain strictly on the server or local environment.

Plugin Architecture

Isolated connector contract separates service details from export generation.

Security Controls

Designed for local and self-hosted security.

Exports are generated on demand. Security controls are built into application endpoints and response pipelines.

Server-Side Credentials

Spotify API keys remain strictly server-side and are never sent to client browsers.

Formula Injection Protection

Exported CSV text fields automatically neutralize formula prefixes (=, +, -, @).

CSRF & Rate Limiting

Post endpoints enforce per-session CSRF tokens and in-memory rate limits.

Browser Security Headers

Includes CSP, nosniff, frame options, and HSTS in production.
